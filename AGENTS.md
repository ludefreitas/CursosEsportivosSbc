# Preferências do projeto

- No início de cada dia em que houver atualizações no projeto, preparar e apresentar ao usuário os comandos necessários para enviar as alterações ao GitHub.
- Adaptar os comandos ao nome real da branch atual e aos arquivos modificados.
- Não executar `git push` automaticamente, salvo quando o usuário solicitar explicitamente.
- Manter todos os textos visíveis em português do Brasil com a acentuação correta e preservar a codificação UTF-8.
